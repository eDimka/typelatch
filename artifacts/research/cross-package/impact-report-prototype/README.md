# Package impact report prototype

This experimental interface requires a destination for the same evidence engine frozen in the first impact prototype. It saves every collected fact and issue into one new workspace root JSON file, then returns a bounded summary. The agent must inspect and transform the evidence into its requested answer. It cannot overwrite an existing file.

The response budget is fixed at 8,000 bytes. This interface removes an optional choice that the earlier development session did not use. It changes neither compiler analysis nor supported source scope. It does not build projects, propagate arbitrary values or prove dynamic runtime impact. Every condition retains the same source access, file permissions and native tools.

The actual Codex transport was qualified on independent scratch packages before scoring. The fresh development trial remains separate from earlier runs. No held out task or answer was used to implement this interface.
