# Cross package research

This study extends the earlier localized repair trials. It first measures development tasks, then uses new tasks to test any proposed advantage. Development results cannot establish an edge.

The first batch compares a five package dependency API migration and a ten package symbol impact report. The migration exercises native builds and runtime behavior in every changed package. Dependencies are already upgraded and fixed, so dependency resolution and installation are preparation costs. The impact report distinguishes direct symbol use from conservative package reachability and requires exact source evidence. It proposes a contract change rather than reproducing an upstream bug.

Native tools, Typelatch and Serena receive the same task, installed source and validation. Every condition can use the compiler, language service, package tools and ordinary source reads. The first investigation uses the advertised provider when available; later choices are free. Typelatch must provide usable task evidence before a provider advantage can qualify. Empty or failed calls remain charged.

Native TypeScript and Serena have separately recovered all ten runtime consumer files after activating the relevant projects. A cold project scoped result is not treated as a limitation of the complete tool. Those qualification costs are separate from model performance.

Sessions run sequentially with fresh provider state, exact fixture bytes and complete usage capture. Charge provider preparation and agent time, including indexing, failed calls, fallback and native validation. Report common corpus preparation, copying, independent grading and teardown separately. OS file caches may be warm. No immutable served model snapshot is available. Public upstream code may occur in model training data.

Keep all attempts and category results. The frozen gate requires at least 20 percent lower total tokens and charged time against both controls, aggregate and median paired savings, improvement in each repetition, correct candidate results and independent review. A category claim additionally needs two distinct held out tasks and two repetitions. A single case can justify further investigation, not a claim of superiority. A broad comparative claim also requires a CodeGraph challenge.

The original protocols, provider archives and recorders remain unchanged. The new coordinator and review code are separate. Public evidence includes completed tool actions, exact returned outputs, requested analysis artifacts, changes and independent grades. Model reasoning and assistant message bodies are excluded.

One maintenance candidate was rejected before scoring: its third package repair was redundant under both native and independent checks. A maintenance result will be added only after a task demonstrates necessary behavior changes across package boundaries. No maintenance task is counted in this initial batch.
