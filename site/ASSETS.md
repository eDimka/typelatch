# Original visual assets

The Typelatch site uses an original generated artwork, an original typographic banner, and locally hosted fonts. No asset or layout was copied from the rejected Codegraph exploration.

## Precision latch artwork

`assets/latch-hero.webp` and `assets/latch-hero-small.webp` are optimized versions of artwork generated specifically for this redesign on September 8, 2026 through the image generation tool. The composition shows a precision orange latch holding ivory source sheets. It is a product metaphor, not a screenshot, physical product claim, or visualization of measured data.

The direction asked for electric orange anodized aluminum, ivory ceramic declaration sheets, a near black studio environment, no chips or neon effects, and no fabricated legible code. The larger WebP is 1536 by 1024 pixels. The smaller version is 840 pixels wide. The original generated PNG was retained in the local generation working directory rather than shipped as an additional page download.

## Wordmark and banner

The brand is a plain Typelatch wordmark, with no corner symbol. The favicon is a typographic lowercase t. The README and social image is `assets/readme-banner.png`, rendered at 1200 by 630 pixels from `brand-banner.html`. It combines the original artwork with real HTML text, rather than relying on generated lettering. The source allows future copy and layout changes without regenerating the artwork.

## Fonts

Archivo is by Omnibus Type. IBM Plex Mono is by IBM. Both are distributed under the SIL Open Font License. The Latin WOFF2 files are hosted locally, with their licenses retained under `assets/fonts/`. The font packages used to obtain them were `@fontsource-variable/archivo` and `@fontsource/ibm-plex-mono`. The site requires no external font request.
