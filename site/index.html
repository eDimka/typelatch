typelatch on npm ↗

Install Typelatch

npm install --global typelatch@0.1.1

Node.js 22.12 or newer. The native SQLite dependency may need a C++ toolchain if a prebuilt binary is unavailable.

Give it an exact package

typelatch add kysely@0.28.8

Use the version in your project. Inside an npm project, typelatch sync indexes direct locked dependencies. Indexing needs npm access. Indexed search works offline.

Local by design.
Explicit about the limits.

Package indexing downloads npm artifacts and verifies registry integrity without running their lifecycle scripts. Queries and history stay on your machine. Workspace checks use your installed compiler. Explicit test commands execute local code with your permissions.

Evidence covers the recorded inputs and assertions. It does not certify remote services, excluded files, or general coding success.
