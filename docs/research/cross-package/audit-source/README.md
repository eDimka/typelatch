# Development grading and setup source

This bundle makes the completed cross package development graders, truth, runtime checks and source recipes inspectable. Clean machine setup has not yet been verified. It contains no held out answers or private model reasoning.

The historical files retain their original relative layout under historical/. Local checkout, home and temporary prefixes are replaced with environment placeholders. The manifest records both original and published hashes. Large text files are compressed as gzip; decompression restores the published text exactly. Source licenses are included with each corpus.

The migration fixture uses five production packages with upgraded dependencies already installed. Its baseline is an explicit reversal of six source substitutions from the recorded upstream migration while retaining later corrections. The reference, omission and semantic controls are separate. The impact fixture is a proposed contract analysis. Its original flawed grader and corrected grader remain distinct. Maintenance uses the recorded upstream parent and reference source; public build and API checks are distinct from the independent registry integration. See provenance.json and the qualification receipts.

These scripts refer to prepared local corpora, native tools and historical dependencies. The full installed dependency inventories and binary runtimes are not redistributed. Their frozen identities are recorded in provenance.json and the study protocols. Source tracking manifests and the source bytes used by the completed correctness audits are included. A future portable wrapper must resolve paths, fetch the pinned commits and dependencies, rebuild required projects, reconstruct the integrity inventory and reproduce baseline, reference and negative controls. That work has not been claimed complete here.

Use the study result exports for exact submitted answers, observed actions, returned tool outputs, grades and later correctness audits. This bundle does not reinterpret or replace any original result.
