# Catalog validation environment correction

This separate development fixture preserves the original study and changes only `.typelatch-benchmark/check-runtime.mjs`. The original public runner could not bind Verdaccio to localhost inside the actual coding sandbox. Passing independent repair grades therefore did not establish a completed public workflow.

The new public command still compiles the four affected TypeScript projects and runs the same nine real production API and filesystem cases. It starts no listening server. The independent grader still copies allowed source onto a fresh trusted fixture and executes all twenty-two semantic cases plus the exact upstream catalog installation regression with the registry outside the agent sandbox. This separates public API and build validation from private upstream integration; it does not claim that the public command runs that integration.

`qualify.mjs` executes the baseline and reference public commands through the unchanged Codex capture with `workspace-write`, then runs the full independent grader. These are command transport preflights, not coding scores. Their raw captures remain private. The qualification receipt contains only tool actions, terminal usage, execution metadata and deterministic check results. The source tree is checked unchanged around each no-edit preflight.

The reference, partial-fix rejection controls, upstream source identities and private cases are inherited unchanged from the first development qualification. No old fixture or scoring evidence is edited. Whole fixture copies use independent APFS clones, preserving symlinks. The prepared fixture has no target build outputs; validation rebuilds them, and grading ignores submitted generated outputs.

Run `node artifacts/research/cross-package/maintenance/v2/prepare.mjs` only into a fresh destination, then `node artifacts/research/cross-package/maintenance/v2/qualify.mjs` and `node artifacts/research/cross-package/maintenance/v2/write-descriptor.mjs`. The original pinned runtime and private source receipts are required; these commands are not a portable clean-machine installer.
