# pnpm maintenance qualification

This task uses a real upstream regression, pnpm issue15481 and repair PR15493. The selected source is the full pnpm v10.32.1 TypeScript monorepo, commit `eaae772717d3d36903960af125a2a2ff9d34fe09`. The later repair is commit `b809cfdd75145edf12dc56332752946b4b7fb4e1`, whose direct parent is `b34ab3f7e16c99b9064f6a7edc99c7a78b4ba1fe`. This is an explicitly adapted backport, not a claim that the older snapshot is that repair's parent.

The task asks for correct changed-project selection after a tracked file moves between projects. It supplies no implementation path or repair hint. Every arm receives the same prompt, source, dependencies and native validation command.

Qualification attempt002 passed. The unmodified source fails1 of3 public cases and7 of15 private cases. The reference passes all3 public and15 private cases. A deliberately overbroad implementation fails13 private cases, showing that selecting unrelated projects is rejected. Real Git repositories and actual rename detection are used. Private cases also cover reverse moves, renamed filenames, nested and spaced paths, staged changes, same-project moves, test-only classification, ignored files, ordinary addition/deletion/edit and no changes.

Only the real constants/error prerequisite projects are built using the repository TypeScript5.5.4 compiler. The real changed-package TypeScript implementation executes through pinned external tsx4.23.13. One root script, `npm run test:typelatch-benchmark`, invokes the supplied public runner. This does not claim a complete upstream CLI, build or test pass.

The prepared baseline tree digest is `4456c2defad3db384f3febb45378aca969fd0d3362c29ce5e4d2843e2690fc6a`. The installed source initially inherited seven committed symlinks whose relative text had been rewritten to absolute paths. Attempt001's behavior results are retained, but its `setup-review.json` marks it ineligible for scored use. Attempt002 restores only those seven links to the exact committed text and records every before/after value. Its prepared corpus has zero external symlink targets. Original source and the retrieval-screen corpus remain unchanged.

Private truth, reference changes and qualification copies are under `../truth-private/maintenance-research`. They must remain outside provider and coding-agent corpora. `qualify.mjs` exports `gradeWorkspace(workspace, initialManifest)` for the coordinator. The grader checks that only existing production TypeScript source changed, runs the private assertions, and confirms validation did not mutate the corpus. The source restrictions and private evaluator are procedural isolation, not an operating-system security boundary.

No coding-agent trial has run. One task cannot establish general monorepo superiority. The separately qualified date-fns task supplies a different repository and behavior. PR15442 is a possible second pnpm task about branch merge-base selection, but shares the filtering subsystem and is not yet qualified; it must not be counted as an independent broad replication. The real dependency migration PR10930 was investigated, but adapting its253 changed files to this older dependency state would need a separately qualified upgrade fixture.
